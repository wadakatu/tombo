案 B「計測」— 深化版

選ばれた B に、没だった A 案の魂 = 朱を一滴だけ移植しました。「朱は"現在地"を指す 1px の線にだけ宿る」という掟がこのシステム最大の指紋です。§1 から §5 まで順に見て、各セクションへの感想をターミナルでください。

§1 — 原則 システムの憲法(3ヶ条)
KEISOKUWADAKATU DESIGN SYSTEM / 仮称
  1. RULE 01

    すべてを測る

    要素は寸法線・目盛・通し番号とともに置かれる。「測られた上でそこにある」精度の気配が紙面の空気を作る。

  2. RULE 02

    銘は等幅

    数字・ラベル・索引・単位はすべてモノスペース。本文は静かなサンセリフで組み、計器の部分だけが等幅で光る。

  3. RULE 03

    朱は現在地

    赤は「いまここ」を指す 1px の線にだけ許される。面に塗った瞬間、それは朱ではなくただの赤になる。
