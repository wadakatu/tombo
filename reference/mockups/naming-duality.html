銘板 — 昼は蜻蛉、夜は蛍。

システムの傘は TOMBO ひとつ(認知を分散させない)。その下にテーマが二つ — 昼の tombo と夜の hotaru。ロゴは同じ虫の文法で、昼は尾が朱(現在地)、夜は尾が発光(蛍光の green)。

THEME 01 — DAY

TOMBO

蜻蛉 — 勝ち虫 / 見当合わせの印

前にしか飛ばない勝ち虫。版を合わせる見当のマーク。昼の図面は紙の白、計器は深緑、現在地は朱。

data-theme="tombo" /* default */
THEME 02 — NIGHT

HOTARU

蛍 — 夜、計器は蛍になる

夜の図面では計器だけが光る。green の増光(#4FC2A2)は文字通りの蛍光。文法は昼と同一、インクの明度だけが変わる。

data-theme="hotaru"
構造は catppuccin の flavors と同じ: システム名 = TOMBO(リポジトリ・npm・呼称)/ テーマ名 = tombo(昼)・hotaru(夜)。--tombo-* トークンの値だけがテーマで入れ替わる。唯一の例外としてロゴの尾: 昼 = 朱の線、夜 = 蛍の発光(ブランドの遊びとしてヒーロー音量でのみ許可)。
