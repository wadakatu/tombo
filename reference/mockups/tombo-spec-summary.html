TOMBO

蜻蛉 — 勝ち虫 / 見当合わせの印。このページ自体が TOMBO で組まれている。
RULE 01

すべてを測る

要素は寸法線・目盛・通し番号とともに置かれる。「測られた上でそこにある」精度の気配。

RULE 02

銘は等幅

数字・ラベル・索引はすべてモノスペース。本文は静かに、計器だけが等幅で光る。

RULE 03

朱は現在地

赤は「いまここ」を指す線にだけ許される。面に塗った瞬間、それは朱ではなくただの赤。

section — 05 / layout & motion

05 —レイアウト・モーション

  • 基本単位 4px / 方眼セル 24px 固定 / セクション律動 docs 64px・LP 96px / 本文最大幅 62ch
  • 角丸は原則 0(図面に丸はない)。例外: 大型パネル 6px・チップ 99px
  • 罫線: 通常 1px hairline / 強調 1.5px ink / 現在地 2px shu
  • モーション =「計器の動き」: 120-180ms・ease-out。針の伸縮と明度遷移のみ。バウンス・パララックス禁止。prefers-reduced-motion 対応
  • 階層は面の明度 1 段 + 罫線(昼は surface まで。+2 段は 1.5px ink 罫で代替)

section — 07 / hotaru rules

07 —hotaru の掟(6 ヶ条)

NIGHT — 夜、計器は蛍になる
  1. 影を使わない — 階層は明度 1 段(paper → surface → raised)と罫線
  2. 方眼は半減 — 発光する画面では物理量を下げて同じ「気配」に
  3. 計器は増光 — green #0E5A47 → #4FC2A2。夜のコックピット
  4. 朱は変わらず線 — 役割は昼と完全に同一
  5. コードは沈めない — 夜は罫線の枠のみ。「黒の上の黒」を作らない
  6. 純黒・純白の禁止 — 図面はあくまで紙である

切替: prefers-color-scheme をデフォルトに、[data-theme] で明示上書き。

section — 09 / decision record

09 —決定記録

3 方向案(朱筆 / 計測 / 一色)から B「計測」をユーザーが選択。没案 A の魂(朱)を「朱は現在地」の掟として移植 — 深緑の計器 UI + 朱の 1px 線は既存システムに存在しない組み合わせ。名前 TOMBO・HOTARU はともにユーザー発案。趣味モチーフ(写真・HHKB)とターミナル風の単独継承は不採用、mono は「計器」の文法として昇華。スコープ外(v1): Figma・JS コンポーネント・npm 公開。
