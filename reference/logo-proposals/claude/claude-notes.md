# Claude logo proposals — TOMBO

- **claude-01 見当 (kento)** — 現行ドラフトの精錬版。見当合わせの十字に翅二対、頭は版の合いマークの円、尾だけが朱。最小構成で 16px でも潰れない。
- **claude-02 物差し (monosashi)** — 蜻蛉の胴体そのものが目盛付きのルーラー。「すべてを測る」を身体で体現し、最下段の目盛(現在の読み値)だけが朱。TOMBO の思想を一番語れる案。
- **claude-03 刻印 (kokuin)** — Archivo 900 のワードマークを寸法線で測った案。名前すら測られている。朱のティックは 62% 位置(brand の現在地)。リポジトリヘッダーや README 向き、favicon には 01/02/04 を併用。
- **claude-04 四隅 (yosumi)** — 翅をトンボ(裁ち落としの四隅マーク)そのもので構成。S-01 署名要素との一体感が最も強く、カードの四隅マークと同じ文法で振る舞う。
