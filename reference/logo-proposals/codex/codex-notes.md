# TOMBO logo proposals

## codex-01 — 見当蜻蛉

印刷の見当円と十字を蜻蛉の頭・胴に重ね、4本の直線だけで翼を正面図として描いた案です。尾の目盛を「測る」思想につなげ、最後の朱い横線を現在地として置いています。

## codex-02 — 前進軸

右向きの測定軸を胴体にし、後方へ払った4枚の翼で「前にしか進まない勝ち虫」を表現した案です。先端は見当円、途中の朱い縦目盛は現在位置で、横長の運動を正方形の中に収めています。

## codex-03 — 計測銘

Archivo 900の `TOMBO` を主役に、四隅の断裁トンボと下部の寸法線で「測られた銘」にしたワードマーク案です。上の見当標は小サイズでの識別点になり、寸法線中央の朱い目盛が現在地を示します。

## codex-04 — 原点印

翼に見立てたTの横棒と、見当円に見立てたOを一つの計測印へ圧縮したモノグラム案です。四隅の断裁トンボが座標系をつくり、垂直軸の終点にある朱い目盛が原点を固定します。

全案とも主線は `currentColor` で構成しているため、既定の深緑からhotaru用の明緑へCSSで差し替えられます。朱は位置を示す細いストロークにだけ使用しています。
