# TOMBO CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automate TOMBO's quality gates (Baseline, contrast, size, banner/tag, JS validity) in GitHub Actions behind a single `npm run check` shared by CI and local dev.

**Architecture:** A dev-only `package.json` hosts stylelint + `stylelint-plugin-use-baseline`. `scripts/check.sh` runs five gates in sequence; `.github/workflows/ci.yml` and local `npm run check` both call it. The Baseline allow-list lives in `stylelint.config.mjs` (not `tombo.css`), pinned empirically. Two new dependency-free Python instruments (`check_size.py`, `check_banner.py`) join the existing `check_contrast.py`.

**Tech Stack:** GitHub Actions, Node 20 + npm, stylelint 16 + stylelint-plugin-use-baseline, Python 3 stdlib, bash.

## Global Constraints

- **No version bump** — `tombo.css` and `tombo.js` are UNCHANGED; banners stay `v0.12.0`. Commits are `ci:`/`chore:`. This is CI infra, not a release.
- **Single-file distribution invariant** — `package.json` carries **devDependencies only**, `"private": true`, no `main`/`exports`. Consumers still vendor `tombo.css`; they never `npm install` TOMBO.
- **Allow-list ledger lives in `stylelint.config.mjs`** via `ignoreProperties`/`ignoreFunctions`/`ignoreSelectors`/`ignoreAtRules` — each entry carries a one-line justification comment. **`tombo.css` is never edited.**
- **Baseline threshold = `available: "widely"`.**
- **stylelint scope = `tombo.css` only** (examples' inline `<style>` is demo scaffolding, not the product).
- **CI runs the same `npm run check` as local**; five gates, any failure → non-zero exit.
- Commit trailer on every commit: `Claude-Session: https://claude.ai/code/session_01CYKP1wE7CusnhuQm9CxTue`. No `Co-Authored-By`. English Conventional Commits. Branch `feature/ci`.
- Spec: `docs/superpowers/specs/2026-07-24-tombo-ci-design.md`. Current gzip baselines: `tombo.css` 10,243 B, `tombo.js` 1,273 B.

      ],

    "declaration-block-no-duplicate-properties": true,

- [ ] **Step 4: Run stylelint and read every violation.**

Run: `npx stylelint tombo.css`
This is the empirical pinning step. Two categories of output are expected and handled differently:
- **`plugin/use-baseline` violations** — each names a non-widely feature. For every one, decide: is it a deliberate PE feature? If yes, add it to the correct `ignore*` list with a one-line justification comment (e.g. `print-color-adjust` → `ignoreProperties`; `break-inside`/`break-after`/`orphans`/`widows` → `ignoreProperties` if flagged; an at-rule → `ignoreAtRules`). If a violation is NOT deliberate, that's a real finding — stop and raise it. Do NOT blanket-disable the rule.
- **error-rule violations** (from the six rules in Step 3) — if any rule flags intentional, hand-authored CSS (not a real bug), remove that rule from the config. Keep only rules that report zero on the current `tombo.css`.

- [ ] **Step 1: Write `scripts/check_size.py`.**

```python
#!/usr/bin/env python3
"""TOMBO size budget — gzipped-byte ceilings for the distributed files.

Catches silent bloat. Ceilings have headroom over the current sizes but fail
on a real regression (e.g. a near-doubling). Exit 1 if any file is over budget.
"""
import gzip
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent

# (path, gzipped-byte ceiling)
BUDGET = [
    ("tombo.css", 12 * 1024),  # 12 KiB — current ~10.0 KiB
    ("tombo.js",   2 * 1024),  #  2 KiB — current ~1.2 KiB
]

def gz_size(path: Path) -> int:
    return len(gzip.compress(path.read_bytes(), 9))

def main() -> int:
    failed = False
    for name, ceiling in BUDGET:
        size = gz_size(ROOT / name)
        ok = size <= ceiling
        failed |= not ok
        print(f"{'PASS' if ok else 'FAIL'}  {name:10} {size:6} B gzip  (ceiling {ceiling} B)")
    return 1 if failed else 0

if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 3: Write `scripts/check_banner.py`.**

```python
#!/usr/bin/env python3
"""TOMBO banner/tag integrity.

Asserts the version is consistent across: tombo.css banner (line 1),
tombo.js banner (line 1), and the three README vendoring pins
(`git ... show vX.Y.Z:...`). When run on a tag (GITHUB_REF=refs/tags/vX.Y.Z),
also asserts the tag matches. Exit 1 on any mismatch.
"""
import os
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
VER = re.compile(r"v(\d+\.\d+\.\d+)")

def first_line_version(path: Path) -> str | None:
    line = path.read_text().splitlines()[0]
    m = VER.search(line)
    return m.group(1) if m else None

def readme_pin_versions(path: Path) -> list[str]:
    # lines like: git -C /path/to/tombo show v0.12.0:tombo.css > ...
    return [m.group(1) for m in re.finditer(r"show v(\d+\.\d+\.\d+):", path.read_text())]

def main() -> int:
    versions = {}
    versions["tombo.css banner"] = first_line_version(ROOT / "tombo.css")
    versions["tombo.js banner"] = first_line_version(ROOT / "tombo.js")
    pins = readme_pin_versions(ROOT / "README.md")
    for i, p in enumerate(pins, 1):
        versions[f"README pin {i}"] = p

    print("versions found:")
    for k, v in versions.items():
        print(f"  {k:18} {v}")

    found = [v for v in versions.values() if v]
    if len(pins) != 3:
        print(f"FAIL  expected 3 README vendoring pins, found {len(pins)}")
        return 1
    if None in versions.values():
        print("FAIL  a banner has no vX.Y.Z version")
        return 1
    if len(set(found)) != 1:
        print(f"FAIL  version mismatch across banners/pins: {sorted(set(found))}")
        return 1
    agreed = found[0]
    print(f"PASS  all banners and pins agree: v{agreed}")

    ref = os.environ.get("GITHUB_REF", "")
    m = re.fullmatch(r"refs/tags/v(\d+\.\d+\.\d+)", ref)
    if m:
        tag = m.group(1)
        if tag != agreed:
            print(f"FAIL  tag v{tag} != banner/pin v{agreed}")
            return 1
        print(f"PASS  tag v{tag} matches banners/pins")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

    branches: [main]

      - uses: actions/checkout@v4
